# BetterGI 星轨设计语言规范

## 1. 概述

本规范旨在定义BetterGI 星轨项目的设计语言，包括颜色、字体、间距、响应式设计等方面，确保应用程序具有一致的视觉风格和用户体验。

## 2. 颜色规范

### 2.1 主色调

| 名称 | 颜色值 | 用途 |
|------|--------|------|
| primary | #66ccff | 主要按钮、标题、强调文本 |
| secondary | #4a90e2 | 次要按钮、辅助元素 |
| success | #5cb85c | 成功状态、确认按钮 |
| warning | #f0ad4e | 警告状态、提示信息 |
| danger | #d9534f | 错误状态、删除按钮 |
| info | #5bc0de | 信息提示、帮助文本 |

### 2.2 中性色

| 名称 | 颜色值 | 用途 |
|------|--------|------|
| background | #ffffff | 窗口背景、卡片背景 |
| surface | #f5f7fa | 面板背景、分组框背景 |
| border | #e0e0e0 | 边框、分隔线 |
| text | #333333 | 主要文本 |
| text_secondary | #666666 | 次要文本、说明文字 |
| text_disabled | #999999 | 禁用状态文本 |

## 3. 字体规范

### 3.1 字体家族

- **主要字体**：得意黑 (SmileySans-Oblique) - 用于标题、按钮、重要提示
- **次要字体**：思源宋体 (Source Han Serif CN) - 用于正文、说明文字、表格内容

### 3.2 字体大小

| 用途 | 字体 | 大小 | 权重 |
|------|------|------|------|
| 应用标题 | 得意黑 | 24px | Bold |
| 窗口标题 | 得意黑 | 18px | Bold |
| 分组框标题 | 得意黑 | 14px | Bold |
| 按钮文本 | 得意黑 | 12px | Medium |
| 正文文本 | 思源宋体 | 12px | Regular |
| 说明文字 | 思源宋体 | 10px | Regular |
| 表格内容 | 思源宋体 | 11px | Regular |

## 4. 间距规范

### 4.1 容器边距

| 容器类型 | 边距 |
|----------|------|
| 主窗口 | 12px |
| 对话框 | 20px |
| 分组框 | 15px |
| 面板 | 8px |

### 4.2 控件间距

| 控件类型 | 间距 |
|----------|------|
| 按钮间距 | 8px |
| 输入框间距 | 10px |
| 标签与控件间距 | 5px |
| 分组框内部间距 | 12px |

## 5. 控件样式规范

### 5.1 按钮样式

- 主要按钮：使用主色调，圆角8px
- 次要按钮：使用中性色，圆角8px
- 按钮高度：30px
- 按钮宽度：根据内容自适应，最小80px
- 对话框按钮：统一宽度100px

### 5.2 输入控件样式

- 边框：1px 实线，颜色为border色值
- 圆角：6px
- 背景：白色
- 聚焦状态：边框颜色变为primary色值，添加阴影效果
- 输入框高度：32px

### 5.3 分组框样式

- 边框：1px 实线，颜色为border色值
- 标题位置：顶部，背景为surface色值
- 标题字体：得意黑，14px，Bold

## 6. 响应式设计规范

### 6.1 设计原则

- **灵活性**：布局应能适应不同屏幕尺寸和分辨率
- **可用性**：在小屏幕上保持良好的可用性和可读性
- **一致性**：在不同尺寸下保持一致的视觉风格
- **性能**：响应式设计不应影响应用性能

### 6.2 窗口尺寸规范

| 窗口类型 | 最小尺寸 | 推荐尺寸 | 最大尺寸 |
|----------|----------|----------|----------|
| 主窗口 | 1100x750 | 1200x820 | 无限制 |
| 事件编辑对话框 | 450x700 | 500x800 | 无限制 |
| 简单对话框 | 300x200 | 400x300 | 600x400 |

### 6.3 布局策略

- **弹性布局**：使用QVBoxLayout和QHBoxLayout的stretch属性管理空间分配
- **分割器**：使用QSplitter实现可调整的布局，设置合理的最小/最大宽度
- **滚动区域**：对于长内容，使用QScrollArea确保内容可访问
- **响应式控件**：为控件设置适当的SizePolicy，确保其能根据容器大小调整

### 6.4 控件尺寸策略

| 控件类型 | 尺寸策略 | 说明 |
|----------|----------|------|
| 输入框 | Expanding, Fixed | 水平方向扩展，垂直方向固定高度 |
| 组合框 | Expanding, Fixed | 水平方向扩展，垂直方向固定高度 |
| 按钮 | Fixed, Fixed | 固定尺寸，根据内容调整 |
| 标签 | Preferred, Fixed | 水平方向根据内容调整，垂直方向固定高度 |
| 面板 | Expanding, Expanding | 水平和垂直方向都扩展 |

### 6.5 响应式布局示例

```python
# 主窗口布局示例
splitter = QSplitter(Qt.Orientation.Horizontal)
left_panel = QWidget()
left_panel.setMinimumWidth(200)
left_panel.setMaximumWidth(450)
right_panel = QWidget()
splitter.addWidget(left_panel)
splitter.addWidget(right_panel)

# 对话框布局示例
layout = QVBoxLayout()
scroll_area = QScrollArea()
scroll_area.setWidgetResizable(True)
layout.addWidget(scroll_area)

# 控件尺寸策略示例
input_edit = QLineEdit()
input_edit.setSizePolicy(QSizePolicy.Policy.Expanding, QSizePolicy.Policy.Fixed)
```

### 6.6 适配不同尺寸的设计建议

1. **小屏幕适配**：
   - 确保所有内容可访问，避免内容溢出
   - 优化控件排列，减少不必要的空白
   - 确保按钮和可交互元素足够大，便于点击

2. **大屏幕适配**：
   - 合理利用空间，避免内容过于集中
   - 保持适当的间距，提高可读性
   - 可以考虑添加更多信息或功能面板

3. **动态调整**：
   - 根据窗口大小动态调整控件布局
   - 考虑使用QSizeGrip允许用户调整窗口大小
   - 测试不同尺寸下的显示效果

## 7. 动画与过渡效果

### 7.1 窗口动画

- 窗口打开/关闭：使用淡入淡出效果
- 对话框弹出：使用淡入和缩放效果
- 面板显示/隐藏：使用平滑过渡效果

### 7.2 控件动画

- 按钮悬停：轻微缩放或颜色变化
- 输入框聚焦：边框颜色变化和阴影效果
- 进度指示：平滑的进度动画

## 8. 图标规范

### 8.1 图标风格

- 使用简洁、现代的线条风格图标
- 图标尺寸：16x16, 24x24, 32x32
- 图标颜色：主要使用text色值，强调状态使用primary色值

### 8.2 图标使用

- 统一使用 `utils.py` 中的 `load_icon_universal()` 函数加载图标
- 图标文件应放在项目根目录或 `logo/` 目录下
- 禁止在代码中硬编码图标路径

## 9. 总结

本设计语言规范定义了BetterGI 星轨项目的视觉风格和设计原则，包括颜色、字体、间距、响应式设计等方面。所有开发人员应严格遵循本规范，确保应用程序具有一致的视觉风格和良好的用户体验。

规范将根据项目的发展和需求变化进行定期更新，以适应新的设计趋势和技术要求。
