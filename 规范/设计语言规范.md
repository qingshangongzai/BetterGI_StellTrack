#### 1.1.3 主题切换

应用程序支持浅色和深色两种主题模式，用户可以在设置中切换主题。主题切换后，所有UI组件应立即更新为对应主题，无需重启应用。

**主题切换原则：**


1. 主色（#66ccff）在浅色和深色主题中保持一致，确保品牌识别性
2. 深色主题使用纯黑色背景（#000000）和卡片背景（#000000）
3. 文本颜色在深色主题中调整为浅灰色（#E0E0E0），确保可读性
4. 边框颜色在深色主题中调整为深灰色（#2A2A2A），与背景协调
5. 状态颜色（成功、错误、警告）在深色主题中调整为更柔和的色调

#### 2.0.3 对话框按钮布局规范

所有对话框下方的「确认」「关闭」「确定」「取消」等按钮需要**居中显示**，确保视觉平衡和整体美观。

**布局要求：**

- 对话框按钮区域使用水平盒模型布局（如 PyQt 中的 `QHBoxLayout`）
- 按钮前后均添加弹性空间（`addStretch()`），实现居中对齐
- 多按钮场景时，按钮间距保持一致（通常 10px）
- 按钮总宽度不超过对话框内容宽度

**实现示例（PyQt6）：**

```python
button_layout = QHBoxLayout()
button_layout.addStretch()  # 左侧弹性空间
button_layout.addWidget(ok_button)
button_layout.addWidget(cancel_button)
button_layout.addStretch()  # 右侧弹性空间
```

**注意：** PyQt6不支持CSS的flexbox布局，请使用QHBoxLayout配合addStretch()实现按钮居中对齐。

#### 2.0.4 消息框滚动条规范

当消息内容较长时，消息框应支持滚动条功能，确保用户可以查看完整内容。

**滚动条要求：**

- 使用 `QScrollArea` 包装消息内容
- 滚动区域设置最大高度为 200px，避免弹窗内容区域过高
- 对话框整体设置最大高度为 310px，确保弹窗不会无限制拉长
- 启用水平和垂直滚动条（按需显示）
- 保持原有宽度、内容居中对齐和动画效果不变

**实现示例（PyQt6）：**

```python
# 创建滚动区域
scroll_area = QScrollArea()
scroll_area.setMaximumHeight(200)
scroll_area.setHorizontalScrollBarPolicy(Qt.ScrollBarPolicy.ScrollBarAsNeeded)
scroll_area.setVerticalScrollBarPolicy(Qt.ScrollBarPolicy.ScrollBarAsNeeded)
scroll_area.setWidgetResizable(True)
scroll_area.setStyleSheet(f"QScrollArea {{ border: none; background-color: {UnifiedStyleHelper.get_instance().COLORS['bg']}; }}")

# 创建消息标签
message_label = QLabel(message)
message_label.setAlignment(Qt.AlignmentFlag.AlignCenter)
message_label.setStyleSheet(f"QLabel {{ font-size: 13px; color: {UnifiedStyleHelper.get_instance().COLORS['text']}; }}")

# 将消息标签放入滚动区域
scroll_area.setWidget(message_label)
layout.addWidget(scroll_area)

# 设置对话框尺寸
dialog.adjustSize()
dialog.setFixedWidth(min(dialog.width() + 20, 400))
dialog.setMaximumHeight(310)  # 限制对话框整体最大高度
```

- `ChineseMessageBox.show_warning()` - 警告消息框

- `ChineseMessageBox.show_info()` - 信息消息框

**注意：** 滚动条样式应遵循全局滚动条样式规范（参考 2.0.5 节）。

## 7. 设计原则


1. **简洁性**：采用扁平化设计，减少视觉干扰
2. **一致性**：所有组件使用统一的颜色、字体和间距
3. **可用性**：清晰的视觉层次和反馈机制
4. **可访问性**：确保文本与背景的对比度符合标准
5. **响应式**：适配不同屏幕尺寸

## 8. 响应式设计规范

### 8.1 响应式设计原则

响应式设计是指界面能够根据窗口尺寸和屏幕分辨率自动调整布局和控件大小，确保在不同设备上都能提供良好的用户体验。

**核心原则：**


1. 界面应支持窗口大小调整，布局能够自适应
2. 设置合理的最小尺寸，确保在小屏幕下仍能正常使用
3. 使用弹性布局和尺寸策略，避免固定尺寸限制
4. 长内容区域应使用滚动区域，确保内容可访问
5. 控件排列应使用弹性空间，实现自适应分布

### 8.2 响应式布局实现

#### 8.2.1 主窗口响应式布局

主窗口应支持窗口大小调整，左右面板能够根据窗口宽度自动调整比例。

**布局要求：**

- 使用 `QSplitter` 实现左右面板的可调整布局

#### 8.2.2 对话框响应式布局

- 使用 `QScrollArea` 包装长内容区域
- 控件使用弹性尺寸策略，支持内容自适应
- 按钮区域使用居中布局，添加弹性空间
- 对于特定对话框，可以设置固定宽度，但允许高度在合理范围内调整

### 8.3 控件尺寸策略

使用 `QSizePolicy` 控制控件的大小行为，实现响应式布局。

**尺寸策略类型：**


1. **Fixed**：固定尺寸，不随布局变化

   ```python
   widget.setSizePolicy(QSizePolicy.Policy.Fixed, QSizePolicy.Policy.Fixed)
   ```
2. **Minimum**：最小尺寸，可以扩展

   ```python
   widget.setSizePolicy(QSizePolicy.Policy.Minimum, QSizePolicy.Policy.Minimum)
   ```
3. **Preferred**：首选尺寸，可以调整

   ```python
   widget.setSizePolicy(QSizePolicy.Policy.Preferred, QSizePolicy.Policy.Preferred)
   ```
4. **Expanding**：可扩展，尽可能占据空间

   ```python
   widget.setSizePolicy(QSizePolicy.Policy.Expanding, QSizePolicy.Policy.Expanding)
   ```

**控件尺寸策略规范：**

|控件类型 |水平策略 |垂直策略 |说明 |
|---|---|---|---|
|主窗口容器 |Preferred |Expanding |水平首选，垂直可扩展 |
|左侧面板 |Preferred |Expanding |水平首选，垂直可扩展 |
|右侧面板 |Expanding |Expanding |水平和垂直都可扩展 |
|事件编辑区域 |Expanding |Expanding |水平和垂直都可扩展 |
|输入框 |Expanding |Fixed |水平可扩展，垂直固定 |
|下拉框 |Expanding |Fixed |水平可扩展，垂直固定 |
|按钮 |Fixed |Fixed |水平和垂直都固定 |
|分组框 |Expanding |Preferred |水平可扩展，垂直首选 |
|滚动区域 |Expanding |Expanding |水平和垂直都可扩展 |

### 8.4 滚动区域应用

长内容区域应使用 `QScrollArea` 包装，确保内容可访问。

**滚动区域设置要求：**

- 设置 `setWidgetResizable(True)` 使内容自适应
- 合理设置滚动条策略：`ScrollBarAsNeeded` 或 `ScrollBarAlwaysOff`
- 水平滚动条通常设置为 `ScrollBarAlwaysOff`，避免不必要的水平滚动
- 垂直滚动条设置为 `ScrollBarAsNeeded`，仅在内容超出时显示

**滚动区域示例：**

```python
from PyQt6.QtWidgets import QScrollArea, QWidget, QVBoxLayout

# 创建滚动区域
scroll_area = QScrollArea()
scroll_area.setWidgetResizable(True)
scroll_area.setHorizontalScrollBarPolicy(Qt.ScrollBarPolicy.ScrollBarAlwaysOff)
scroll_area.setVerticalScrollBarPolicy(Qt.ScrollBarPolicy.ScrollBarAsNeeded)

# 创建内容部件
content_widget = QWidget()
layout = QVBoxLayout(content_widget)
layout.setSpacing(12)
layout.setContentsMargins(5, 5, 5, 5)

# 添加内容到布局
layout.addWidget(widget1)
layout.addWidget(widget2)
layout.addStretch()

# 设置滚动区域的内容
scroll_area.setWidget(content_widget)
```

### 8.5 响应式布局示例

#### 8.5.1 示例1：主窗口布局

```python
from PyQt6.QtWidgets import QWidget, QVBoxLayout, QHBoxLayout, QSplitter, QSizePolicy

# 创建主窗口布局
main_layout = QVBoxLayout(central_widget)
main_layout.setSpacing(8)
main_layout.setContentsMargins(12, 12, 12, 12)

# 创建分割器
splitter = QSplitter(Qt.Orientation.Horizontal)
splitter.setChildrenCollapsible(False)
splitter.setHandleWidth(0)

# 创建左侧面板
left_panel = QWidget()
left_panel.setMinimumWidth(200)
left_panel.setMaximumWidth(450)
left_panel.setSizePolicy(QSizePolicy.Policy.Preferred, QSizePolicy.Policy.Expanding)
left_layout = QVBoxLayout(left_panel)
left_layout.setSpacing(12)
left_layout.setContentsMargins(8, 8, 8, 8)

# 创建右侧面板
right_panel = QWidget()
right_panel.setSizePolicy(QSizePolicy.Policy.Expanding, QSizePolicy.Policy.Expanding)
right_layout = QHBoxLayout(right_panel)
right_layout.setSpacing(12)
right_layout.setContentsMargins(8, 8, 8, 8)

# 添加面板到分割器
splitter.addWidget(left_panel)
splitter.addWidget(right_panel)

# 添加分割器到主布局
main_layout.addWidget(splitter, 1)
```

from PyQt6.QtWidgets import QDialog, QVBoxLayout, QScrollArea, QSizePolicy

class ResponsiveDialog(QDialog):
    def __init__(self, parent=None):

### 8.6 响应式设计注意事项


1. **避免固定尺寸**：尽量避免使用 `setFixedSize()` 和 `setFixedWidth()`，除非确实需要固定尺寸
2. **合理设置最小尺寸**：确保在小屏幕下仍能正常使用，但不要设置过大的最小尺寸
3. **使用弹性布局**：充分利用 `addStretch()` 和 `QSizePolicy` 实现自适应布局
4. **测试不同尺寸**：在不同窗口尺寸和屏幕分辨率下测试界面显示效果
5. **保持一致性**：响应式设计不应影响界面的一致性和美观性
6. **性能考虑**：复杂的响应式布局可能影响性能，应进行性能测试和优化
