**具体问题：**

   - 每次添加事件都会更新统计信息

```python
# 建议：优化事件表格性能
def add_table_rows(self, rows_data):
    """批量添加表格行 - 高性能版本"""
    if not rows_data:
        return
    
    # 禁用更新，提高性能
    self.events_table.setUpdatesEnabled(False)
    
    try:
        # 获取当前行数量
        current_row_count = self.events_table.rowCount()
        # 计算新的行数量
        new_row_count = current_row_count + len(rows_data)
        
        # 一次性设置行数量
        self.events_table.setRowCount(new_row_count)
        
        # 批量填充数据
        for i, row_data in enumerate(rows_data):
            row_position = current_row_count + i
            for col, data in enumerate(row_data):
                item = QTableWidgetItem(str(data))
                item.setTextAlignment(Qt.AlignmentFlag.AlignCenter)
                self.events_table.setItem(row_position, col, item)
    finally:
        # 重新启用更新
        self.events_table.setUpdatesEnabled(True)
```

#### 5.2.2 样式刷新性能

**问题描述：** 主题切换时，样式刷新可能存在性能问题。

**具体问题：**

1. **递归刷新**

   - 可以考虑延迟刷新或批量刷新

2. **样式表重建**

**建议：**

```python
# 建议：优化样式刷新性能
def refresh_theme_styles(self):
    """刷新控件的样式，应用当前主题"""
    helper = UnifiedStyleHelper.get_instance()
    
    # 检查是否需要刷新
    if hasattr(self, '_last_theme_mode') and self._last_theme_mode == helper.theme_mode:
        return
    
    # 更新自身样式
    self.setStyleSheet(helper.get_xxx_style())
    
    # 批量刷新子控件
    children_with_refresh = [child for child in self.findChildren(QWidget) 
                            if hasattr(child, 'refresh_theme_styles')]
    
    for child in children_with_refresh:
        child.refresh_theme_styles()
    
    # 记录当前主题模式
    self._last_theme_mode = helper.theme_mode
```

def validate_file_path(self, file_path):
    """验证文件路径安全性
    
    Args:
        file_path: 文件路径
        
    Returns:
        bool: 路径是否安全
    """
    # 规范化路径
    normalized_path = os.path.normpath(file_path)
    
    # 检查路径遍历
    if '..' in normalized_path:
        return False
    
    # 检查路径是否在允许的目录内
    allowed_dir = get_user_data_dir()
    if not normalized_path.startswith(allowed_dir):
        return False
    
    return True
